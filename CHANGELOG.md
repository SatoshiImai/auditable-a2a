# Changelog

All notable changes to the Auditable A2A specification are documented here. Versions are `0.x` drafts: each version has its own extension URI (§4.1), and a new version may make breaking changes.

This changelog is informative. Normative force (the RFC 2119 keywords) lives only in the specification; the summaries below merely describe it.

## v0.1 - 2026-10-16

Initial release: the extension `https://timberlandchapel.com/a2a/extensions/auditable-a2a/0.1`, on A2A 1.0.0 and `auditable-mcp/0.4`, with its JSON Schemas, conformance vectors, and an end-to-end example captured from the SDKs' walk.
